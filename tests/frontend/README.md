# Panel preview

Mock data and a preview harness for the Tariffy panel (`custom_components/tariffy/frontend/tariffy-panel.js`).

- `fixtures.json`: what `tariffy/contracts` returns for six realistic contracts, generated by the **real backend**.
  `tests/test_panel_fixtures.py` fails when the file is out of date. Regenerate with
  `UPDATE_FIXTURES=1 pytest tests/test_panel_fixtures.py`.
- `preview.html`: loads the panel with a mock `hass`. Serve the repository root (for example `python -m http.server`)
  and open `/tests/frontend/preview.html?lang=de`. Parameters: `lang=de|en`, `state=loading|empty|error`, `narrow=1`.
- `screenshots.mjs`: renders the preview in headless Chromium with the date fixed to 2026-07-12 and writes screenshots to
  `docs/panel-preview/`. Needs Playwright: `node tests/frontend/screenshots.mjs`. Not part of CI.
